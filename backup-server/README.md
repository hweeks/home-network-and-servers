# backup server

## overview

this guide is focusing on building a new backup server for a home lab.

## components

1. chassis - Rosewell 2U Rackmount Case RSV-Z2800U
2. psu - Corsair SF750 80 Plus Platinum ATX Power Supply
3. motherboard - ASUS Pro B550M/C/CSM AM4
4. cpu - AMD Ryzen 5 5600G Cezanne (Zen 3) 6-Core 3.9 GHz Socket AM4 65W
5. ram - 2x Crucial 16Gb DD4 2400 (PC4 19200) 288-Pin UDIMM ECC CL17
6. ssd - Samsung SSD 9100 Pro 1Tb
7. 3x hdds - 3x Seagate IronWolf Pro 20Tb SATA 6Gb/s 7200RPM (ST20000NE0000)
