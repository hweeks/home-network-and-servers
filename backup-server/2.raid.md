# RAID configuration

## zap old partition tables

if disks were previously used, clear partition labels before pool creation

```bash
# install sgdisk if not present
sudo apt install -y gdisk

# zap (irreversible; double-check paths)
sudo sgdisk --zap-all /dev/disk/by-id/ata-HDD_n
```

## create the ZFS RAID‑Z1 pool

```bash
# install ZFS if needed
sudo apt install -y zfsutils-linux

# create pool "tank" with 3×20TB in RAID-Z1
sudo zpool create \
  -o ashift=12 \
  -O compression=lz4 \
  -O atime=off \
  -O xattr=sa \
  -O acltype=posixacl \
  tank \
  raidz1 \
  /dev/disk/by-id/ata-HDD1 \
  /dev/disk/by-id/ata-HDD2 \
  /dev/disk/by-id/ata-HDD3

# verify
zpool status
zfs list
```

> notes:
>
> - `ashift=12` is suitable for 4K‑sector 20TB drives.
> - `compression=lz4` improves performance and saves space.

## create datasets

`zpool create` builds the pool; `zfs create` makes filesystems (datasets) inside the pool with per‑workload settings.

```bash
sudo zfs create tank/backups # general backups
sudo zfs create -o recordsize=1M tank/nextcloud-files # for large user files
sudo zfs create tank/nextcloud-app
sudo zfs create -o recordsize=16K tank/db/nextcloud
sudo zfs create tank/traefik
sudo zfs create tank/tailscale
sudo zfs create tank/syncthing

# verify and view key props
zfs list -o name,used,avail,compressratio,mountpoint
zfs get recordsize tank/nextcloud-files tank/nextcloud-app
```

> notes:
>
> - datasets inherit defaults set at pool creation (`compression=lz4`, `atime=off`, etc.).
> - mountpoints default to `/tank/<dataset>`; override with `-o mountpoint=/path` if desired.
